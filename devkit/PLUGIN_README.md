# MiniBuddies 애니메이션 플러그인

## 제작 에디터

**환경설정 → 에디터 → 제작 에디터 열기**에서 새 플러그인과 캐릭터를 만들 수 있어요. `팩 정보`에 이름, ID, 제작자, 설명을 입력하고 대표 PNG를 고릅니다. 캐릭터 팩의 기본 대표 이미지는 0번 프레임이에요.

- **캐릭터 프레임**에서 직접 그린 256×256 투명 PNG를 번호별로 넣으세요. 기본 자세 0번이 필수입니다. 걷기 1~3번, 낙하 5번, 착지 6번, 잠자기 7번, 점프 10번을 넣으면 각 동작에 맞는 포즈를 보여줄 수 있어요. 기본 동작에서 빠진 프레임은 등록된 포즈로 대체됩니다. `0.png`, `1.png`처럼 이름을 붙인 파일은 일괄 추가할 수 있습니다.
- **트리거 · 조건 · 액션**에서 `개별 동작 추가` 또는 `상호작용 추가`를 선택하세요. 발동 시점은 우클릭 메뉴, 일정 간격, 대기 종료(개별 동작) 또는 캐릭터 접근(상호작용) 중에서 고릅니다. **동작 미리 재생**과 **상호작용 미리 재생**에서 포즈·이동·방향·말풍선·효과를 시간순으로 확인하고, 재생 위치를 바꿔 원하는 순간을 볼 수 있습니다. 상호작용 미리 재생은 함께할 캐릭터들이 자리를 잡은 뒤부터 시작합니다.
- **팩 내보내기**는 `.mbpack` 파일을 만듭니다. 표준 ZIP 압축이며 `.zip`으로 저장해도 같은 포맷입니다. **팩 가져오기**에서 먼저 설명과 대표 이미지를 확인하고, 에디터에서 열어 수정하거나 **이 PC에 설치**할 수 있어요.
- 설치한 캐릭터는 환경설정의 캐릭터 탭을 다시 열어 **그 밖의 친구들**에서 부를 수 있어요. 캐릭터 팩에 포함된 동작은 펫을 우클릭해 **캐릭터 이름이 붙은 놀이 메뉴**에서 바로 실행합니다. 별도로 설치한 동작 팩은 사용할 캐릭터의 **플러그인 → 이 캐릭터에 연결**에서 켭니다.
- **환경설정 → 에디터 → 설치한 팩**에서 캐릭터·스킨·플러그인 팩의 이름과 ID를 확인할 수 있어요. **팩 설치…**로 파일을 고르고 미리보기에서 **이 PC에 설치**를 누르면 바로 추가됩니다. **선택한 팩 삭제…**를 누르면 확인 후 설치된 팩 폴더를 휴지통으로 옮겨요. 사용 중인 스킨을 삭제하면 기본 의상이나 남아 있는 의상으로 돌아갑니다.

공유할 때는 `.mbpack` 파일 하나를 보내면 됩니다. 팩에는 빠른 미리보기용 `pack.json`과 `preview.png`, 동작이 있다면 `plugin.json`과 참조 PNG가 들어갑니다. 캐릭터 팩의 `character/`에는 번호별 PNG, `meta.json`, `name.txt`가 들어 있어 공식 개발자가 검토하고 `chars/<팩 ID>/`로 옮겨 사용할 수 있어요. 공식 캐릭터 목록에 추가하려면 배포 쪽 명단도 갱신해야 합니다. 앱에서 개인용으로 설치하면 저장 경로는 `user-packs/<팩 ID>/`입니다.

### 이동과 방향 전환

- **액션 편집 → 이동·방향**에서 지상 이동이나 점프를 선택하세요. 거리 100은 펫 너비 한 칸이며 양수는 전진, 음수는 후퇴입니다. 제자리 점프는 거리를 0으로 두고 높이만 지정하세요. 다음 단계는 도착 지점에서 시작합니다. 실제 화면에서는 모니터와 현재 발판의 경계 안에서 이동해요.
- 상호작용에서 **캐릭터 따라가기**를 고르면 해당 단계 동안 지정한 캐릭터 쪽으로 수평 이동합니다. **유지할 거리** 안에 들어오면 멈추고, 상대가 멀어지면 다시 움직여요. 이동 속도와 바라볼 방향은 각각 설정합니다.
- 방향은 왼쪽, 오른쪽, 반대 방향 중에서 고릅니다. 상호작용에서는 단계가 시작될 때 지정한 캐릭터 쪽을 바라보게 할 수 있어요. 전진이나 후퇴는 바뀐 방향을 기준으로 움직입니다.
- **포즈·말풍선**에서 캐릭터에 들어 있는 프레임을 이름으로 찾거나 동작에서 띄운 말풍선을 닫을 수 있어요. 포즈, 이동, 방향, 말풍선, 효과를 한 단계에 조합할 수 있습니다. 이동 단계에서 시작한 효과는 펫을 따라갑니다.
- 이 기능을 지원하는 버전에서 재생해야 일정 간격 발동, 이동, 방향 전환, 말풍선 닫기가 적용돼요.

### 스킨 만들기

- 새 캐릭터에 의상을 함께 넣으려면 **새 캐릭터 → 스킨 → 스킨 추가**를 선택하세요. 기존 캐릭터용 의상만 공유하려면 **새 스킨 팩 → 대상 캐릭터**에서 대상을 고르고 스킨을 추가하세요.
- 스킨마다 고유한 ID, 갈아입기 메뉴에 표시할 이름, 0번 기본 자세 PNG가 필요해요. 걷기·낙하 같은 다른 동작도 캐릭터와 같은 번호로 등록할 수 있습니다. 기존 `chars/<캐릭터>@<스킨>/` 폴더는 스킨 탭의 **스킨 폴더 가져오기**로 불러올 수 있어요.
- 내보낸 팩을 가져오면 대상 캐릭터와 스킨 개수를 확인할 수 있어요. **이 PC에 설치**한 다음 대상 펫을 우클릭해서 **옷 갈아입기** 또는 **모습 바꾸기**에서 선택합니다.
- 공식 개발자가 검토할 때는 팩의 `skins/<스킨 ID>/`를 기존 규칙에 맞춰 `chars/<캐릭터 ID>@<스킨 ID>/`로 옮길 수 있어요.

### 효과 만들기

- **효과 → 효과 추가…**에서 이름과 ID를 정한 뒤 원하는 레이어를 추가하세요. 순서대로 그려지는 레이어에 파티클, 빛, 원과 선 또는 직접 가져온 PNG 애니메이션을 섞을 수 있습니다. 동작과 효과에 쓰는 PNG는 256×256 투명 PNG이며 팩당 합계 64장까지 넣을 수 있어요.
- 레이어마다 전체 효과 안에서 시작·종료 시점을 정합니다. 키프레임의 시점은 해당 레이어 안에서의 위치입니다. 키프레임 사이의 X·Y, 크기, 회전, 불투명도는 자동으로 보간됩니다. 위치 단위 100은 펫 스프라이트 한 장의 크기입니다.
- 레이어를 시전자, 상대 또는 두 캐릭터 사이에 배치하고 색상과 합성 방식을 고를 수 있습니다. 개별 동작에서 상대를 기준으로 고른 레이어는 시전자 위치에 그려집니다.
- 저장한 효과는 같은 팩의 개별 동작과 상호작용에서 **액션 편집 → 효과**로 선택하세요. `.mbpack`으로 내보내면 효과와 참조 PNG가 함께 저장됩니다.

## 폴더에서 직접 작성하기

MiniBuddies 폴더의 `plugins/<팩-id>/`에 `plugin.json`과 그림을 넣고 앱을 다시 실행하세요. 팩 ID는 소문자 영문·숫자로 시작하는 폴더 이름입니다. 펫을 우클릭해 **캐릭터 이름이 붙은 놀이 메뉴 → 플러그인 → 플러그인 폴더 열기**로 폴더를 만들 수 있습니다.

같은 메뉴에서 팩 이름을 펼쳐 **이 캐릭터에 연결**을 선택하세요. 메뉴를 다시 열면 연결한 캐릭터에서 행동을 실행할 수 있습니다. 연결은 `settings.json`에 캐릭터별로 저장되며, 같은 캐릭터의 여러 펫과 의상에 적용됩니다.

예를 들어 아래 JSON을 `plugins/tea-break/plugin.json`으로 저장하고 같은 폴더에 `frames/tea.png`, `frames/sip.png`를 넣을 수 있습니다.

```json
{
  "version": 1,
  "name": "차 한 잔",
  "characters": ["reimu", "marisa"],
  "actions": [
    {
      "name": "차 마시기",
      "say": "후우… 따뜻하다.",
      "idle_chance": 0.08,
      "frames": [
        {"file": "frames/tea.png", "ticks": 24},
        {"file": "frames/sip.png", "ticks": 38, "say": "한 모금!"},
        {"ticks": 20, "effect": {"preset": "petal", "colors": ["#ffc4cc", "#fff1cf"], "ticks": 32}},
        {"file": "frames/tea.png", "ticks": 16}
      ]
    }
  ]
}
```

- 그림은 투명 배경 256×256 PNG를 사용합니다. 품질을 위해 발이나 접지 부분을 프레임 간 비슷하게 맞춰 주세요. 앱은 보이는 픽셀의 하단을 기준으로 그림을 배치합니다.
- `characters`는 연결할 수 있는 캐릭터의 `chars/` 폴더 이름입니다. 생략하거나 빈 배열로 두면 개별 동작은 모든 캐릭터에게 연결할 수 있습니다. 상호작용만 들어 있는 팩은 지정된 캐릭터에게만 표시됩니다.
- 개별 동작마다 `characters`로 허용 캐릭터를 더 좁힐 수 있습니다. 내장 PNG를 재사용하려면 액션의 `file` 자리에 `frame`과 프레임 번호를 넣으세요.
- `ticks` 1은 약 16ms입니다. 개별 동작의 `say`는 시작 말풍선이고, 각 `frames` 단계의 `say`는 그 단계가 시작될 때 표시됩니다. 첫 단계에 `say`가 있으면 그 말풍선을 사용합니다.
- `file`과 `frame`을 모두 생략하면 이전 포즈를 유지합니다. 첫 단계라면 기본 자세를 사용합니다. `effect`에는 상호작용과 같은 프리셋·색상·길이를 설정할 수 있어요. 개별 동작의 효과는 캐릭터가 바라보는 방향을 사용하므로 `target`은 생략하세요. 마지막 효과가 더 길면 최종 포즈를 효과가 끝날 때까지 유지합니다.
- 개별 동작과 상호작용의 각 단계에서 `"move": {"distance": 120, "height": 45, "easing": "ease-out"}`으로 이동할 수 있습니다. 거리와 높이는 펫 너비의 백분율입니다. 거리는 −300~300, 높이는 0~150이며 생략하면 0입니다. 높이가 0보다 크면 단계는 2틱 이상이어야 합니다. 속도 곡선은 `linear`(기본), `ease-in`, `ease-out`, `ease-in-out` 중에서 고릅니다.
- `"turn": {"direction": "left"}`에 `left`, `right`, `flip`을 쓸 수 있습니다. 상호작용에서는 `"turn": {"direction": "target", "target": "marisa"}`처럼 다른 캐릭터를 지정할 수 있어요. `"dismiss_speech": true`는 현재 동작이 띄운 말풍선을 닫습니다. 한 단계에 `say`와 함께 쓸 수 없어요.
- `idle_chance`는 펫이 대기를 마쳤을 때 발동할 확률입니다. 개별 동작과 상호작용 모두 확률을 0으로 두고 `"interval_seconds": 30`으로 일정 간격 발동을 설정할 수 있습니다. 간격은 5~3600초이며, 조건이 맞을 때 한 번 발동하고 그때부터 다음 간격을 셉니다. 자동 발동을 설정한 규칙도 메뉴에서 직접 실행할 수 있어요.
- 잘못된 팩은 건너뛰고 `crash.log`에 이유를 남깁니다. 파일을 수정하거나 제거한 뒤 앱을 다시 시작하세요.

## 여러 캐릭터의 상호작용

`interactions`에 함께할 캐릭터와 시간순 동작을 넣을 수 있습니다. 캐릭터 모두에게 팩을 연결한 뒤 같은 모니터와 바닥에 가까이 두면 **같이 놀기 → 플러그인 상호작용**에서 실행됩니다.

```json
{
  "version": 1,
  "name": "별빛 교환",
  "interactions": [
    {
      "name": "레이무와 마리사의 탄막",
      "meet_chance": 0.12,
      "meet_distance": 340,
      "cooldown_seconds": 40,
      "roles": [
        {
          "character": "reimu",
          "steps": [
            {"ticks": 20, "frame": 200},
            {"ticks": 22, "frame": 201, "say": "먼저 할게!",
             "effect": {"preset": "seal", "target": "marisa", "colors": ["#ff7890", "#97c8fd"]}},
            {"ticks": 60, "frame": 0}
          ]
        },
        {
          "character": "marisa",
          "steps": [
            {"ticks": 42, "frame": 0},
            {"ticks": 22, "frame": 201, "say": "이번엔 나야!",
             "effect": {"preset": "spark", "target": "reimu", "colors": ["#cc93ff", "#ffdb68", "#fff7db"]}},
            {"ticks": 16, "frame": 202}
          ]
        }
      ]
    }
  ]
}
```

- 역할은 서로 다른 캐릭터 2~6명입니다. 각 역할의 `steps`가 동시에 시작하며, 각 단계의 `ticks`가 지난 뒤 다음 단계로 넘어갑니다.
- `frame`은 캐릭터에 내장된 PNG의 번호입니다. 팩에서 새 그림을 제공하려면 `frame` 자리에 `"file": "frames/my-cast.png"`를 사용하세요. 둘 다 생략하면 앞선 단계의 포즈를 유지합니다.
- `effect.preset`에는 `seal`, `spark`, `moon`, `fairy`, `freeze`, `petal`, `books`, `sun`, `clock`, `scarlet`, `slash`를 쓸 수 있습니다. `target`으로 상대를, `colors`로 색상을 정합니다. 효과의 `ticks` 기본값은 78이며 단계보다 길게 재생할 수 있습니다.
- 한 단계에 `"follow": {"target": "marisa", "distance": 70, "speed": 3}`를 넣으면 지정한 캐릭터를 따라갑니다. `distance`는 유지할 거리(0~300%), `speed`는 틱마다 이동하는 최대 거리(1~10%)로, 모두 펫 너비 기준입니다. `move`와 `follow` 중 하나를 고르고 `turn`은 별도로 설정하세요.
- `meet_chance`는 자동 놀이 검사 때의 발동 확률입니다. `meet_distance`는 가장 멀리 떨어진 두 캐릭터 사이의 허용 거리이며 일정 간격으로 발동할 때도 적용됩니다. `cooldown_seconds`는 확률로 발동하는 놀이의 최소 재발동 간격입니다. 일정 간격으로 발동하는 상호작용은 환경설정에서 **내버려 둬도 알아서 단체 놀이·합동 장면**을 켜야 합니다.
- 한 팩에 `actions`와 `interactions`를 함께 넣을 수 있습니다. 참여자를 집거나 화면에서 없애거나 팩 연결을 끊으면 진행 중인 놀이가 정리됩니다.

## 개발 파일 위치

- `buddies.py`는 기존 실행 진입점입니다. `minibuddies/app.py`는 앱을 초기화하고 `controllers/`의 캐릭터 관리, 단체 놀이, 데스크톱 연동, 배포 기능 등을 조합합니다.
- `minibuddies/pets/`는 개별 펫의 상태, 이동, 프레임 재생, 마우스 입력을 담당합니다. 캐릭터 데이터는 `minibuddies/catalog/`에 작품·그룹별로 들어 있습니다.
- `minibuddies/ui/`에는 설정창, 우클릭 메뉴, 화면 위 위젯이 있습니다. 설정 탭은 캐릭터, 화면, 놀이, 연동별로 나뉩니다.
- `minibuddies/features/`는 가드 타워·탄막, 날씨, 계절 의상, 변신 등 내장 특수 행동을 기능별로 담습니다. `install_builtin()`이 기존 실행 순서대로 연결합니다.
- `minibuddies/plugins/packs.py`와 `scenes.py`가 JSON·PNG를 검증합니다. `library.py`가 캐릭터별 연결과 개별 동작을, `interactions.py`가 여러 펫의 모임과 재생을 처리합니다. 내장 동방 탄막과 플러그인 탄막은 `minibuddies/effects.py`의 렌더러를 공유합니다.
- `minibuddies/ui/editor/`는 제작 GUI, `minibuddies/authoring/`은 `.mbpack` 형식과 설치를 담당합니다.
- `python -m unittest discover -s tests`로 에디터와 팩 가져오기·내보내기, 캐릭터 연결, 개별 재생, 두 펫의 상호작용과 정리를 검증할 수 있습니다.

배포용 manifest는 배포 시 모듈 경로를 포함해 다시 생성해야 합니다. Android 내보내기가 `buddies.py`에서 캐릭터 데이터를 읽는다면 입력을 `minibuddies/catalog/`에 맞춰야 합니다.
