빙하유·스텔라이브·원숭이 데스크톱 펫 — Claude 연결 가이드
=====================================================

이 펫은 Claude 와 두 가지 방법으로 이어질 수 있어요.

  (A) 숨겨서 묻기 (Claude Code)
      캐릭터를 따닥(더블클릭) → 질문 입력 → 창 없이 캐릭터가 말풍선으로 대답.
      캐릭터마다 나눈 대화를 기억해요.
      물어본 캐릭터에게 "타비한테 춤추라고 해 줘", "다 같이 어비스 콘서트 틀어 줘" 처럼
      다른 친구들에게 시키는 것도 돼요. (환경설정 → 기타 → '다른 친구들에게도 … 시킬 수 있게 하기')

  (B) Claude 데스크톱이 펫을 움직이기 (MCP 연결)
      Claude 데스크톱 채팅에서 "리제한테 인사시켜 줘", "작업 끝나면 알려 줘" 같은 걸 시킬 수 있어요.

둘 다 따로 돈이 드는 API 키는 필요 없어요. Claude 구독(Pro / Max 등) 사용량 안에서 돌아가요.
(Claude 채팅과 같은 사용량 한도를 나눠 써요.)


-----------------------------------------------------
(A) 숨겨서 묻기 — Claude Code 붙이기
-----------------------------------------------------

[준비물]
  - 윈도우 10/11
  - Claude 유료 구독 계정 (Pro, Max, Team 등)

[1] 설치
  방법 1) 펫 폴더의  INSTALL_CLAUDE_CODE.bat  을 더블클릭
          → 설치, PATH 등록, 로그인 화면까지 한 번에 진행돼요.
  방법 2) 직접 하기: 시작 메뉴에서 'PowerShell' 을 열고 아래 한 줄 붙여넣기 → Enter
            irm https://claude.ai/install.ps1 | iex
          진행 표시 없이 조용히 깔리니까 끝날 때까지 기다려요.

[2] 'claude' 를 찾을 수 없다고 나올 때 (PATH 문제)
  설치는 된 거예요. 윈도우가 위치를 모르는 것뿐이에요. PowerShell 에서:
      [Environment]::SetEnvironmentVariable("Path", [Environment]::GetEnvironmentVariable("Path","User") + ";$env:USERPROFILE\.local\bin", "User")
  그다음 PowerShell 창을 새로 열면  claude  만 쳐도 돼요.
  (펫은 이 위치를 직접 찾기 때문에 PATH 등록을 안 해도 동작해요.)

[3] 로그인 (처음 한 번만)
  PowerShell 에서:
      & "$env:USERPROFILE\.local\bin\claude.exe"
  1) 글자 테마 고르기 → 그냥 Enter
  2) 로그인 방법 → 'Claude account with subscription' (구독 계정) 선택
     ※ 'Anthropic Console(API)' 는 고르지 마세요 (API 요금이 따로 나가요)
  3) 브라우저가 열리면 Claude 계정으로 로그인 → 승인(Authorize)
  4) 브라우저에 긴 코드가 나오면, 그 코드를 'PowerShell 창'에 붙여넣고 Enter
     (마우스 우클릭 또는 Ctrl+V)
     ※ 이 코드는 로그인 열쇠예요. 다른 곳(채팅 등)에 붙여넣지 마세요.
  5) "이 폴더를 믿냐(trust this folder)" 질문 → 기본값 'No, exit' 로 Enter 해도 괜찮아요.
     로그인 정보는 이미 저장됐어요. 창은 닫아도 돼요.

[4] 잘 됐는지 확인
  PowerShell 에서:
      & "$env:USERPROFILE\.local\bin\claude.exe" -p "안녕! 한 문장으로 인사해줘"
  인사 한 줄이 나오면 성공.

[5] 펫에서 쓰기
  - 펫을 껐다 켜기 (우클릭 → 종료 → RUN_....bat)
  - 우클릭 → 환경설정 → 기타 탭 → '캐릭터에게 물어보기'
      · 'Claude Code: 찾음 ✓' 이 보이면 준비 끝
      · 방식: '숨겨서 바로 대답 받기 (Claude Code, 창 안 뜸)'
  - 캐릭터를 따닥 → 질문 입력 → "음… 생각 중…" → 말풍선 대답
  - 말풍선은 클릭하면 닫혀요. 글자 크기는 환경설정 → 움직임 → '말풍선 글자 크기'.
  - 대화를 처음부터 다시 하고 싶으면: 기타 탭 → '캐릭터들과 나눈 대화 기억 지우기'

[문제 해결]
  - "Claude Code 로그인이 필요해요" 말풍선 → [3] 로그인을 다시 해 주세요.
  - "Claude Code 가 안 깔려 있어요" 말풍선 → [1] 설치. 설치 후 펫을 껐다 켜기.
  - "앗, 대답을 못 받았어요…" → 사용량 한도에 걸렸거나 인터넷 문제일 수 있어요.
  - 자세한 기록: 펫 폴더의  ask.log


-----------------------------------------------------
(B) Claude 데스크톱이 펫을 움직이기 — MCP 연결 (딸깍)
-----------------------------------------------------

  1) 펫을 켠 상태에서 우클릭 → 환경설정 → 기타 탭
  2) '딸깍! Claude 랑 연결하기' 클릭 → 확인
     → Claude 데스크톱을 잠깐 껐다가, 설정을 넣고, 다시 켜요.
  3) 다시 켜지면 펫이 "Claude 랑 연결됐어요!" 하고 인사해요.
     (Claude 설정 → 개발자 → 로컬 MCP 서버에 'desktop-pet' 이 보이면 성공)

  안 될 때:
  - Claude 가 켜진 채로 설정 파일을 고치면 Claude 가 덮어써 버려요.
    꼭 딸깍 버튼(자동으로 껐다 켬)을 쓰거나, Claude 를 트레이에서까지 완전히 종료한 뒤 고치세요.
  - 수동으로 넣을 때: Claude 설정 → 개발자 → '구성 편집' 으로 열리는 claude_desktop_config.json 맨 위에
        "mcpServers": {
          "desktop-pet": {
            "command": "py",
            "args": ["C:\\Users\\<내 이름>\\AppData\\Roaming\\DesktopPet\\pet_mcp.py"]
          }
        },
    를 넣고 저장 → Claude 완전 종료 후 다시 켜기.

  연결되면 Claude 채팅에서 이렇게 시킬 수 있어요:
    "펫들 상태 보여 줘" / "리제한테 '점심 먹자' 말하게 해 줘" / "어비스 콘서트 틀어 줘"
    "빙하유 한복으로 갈아입혀 줘" / "다 재워 줘" / "작업 끝나면 펫으로 알려 줘"
