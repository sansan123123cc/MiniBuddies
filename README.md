# 꼬마 친구들 (데스크톱 펫)

바탕화면을 돌아다니는 꼬마 친구들이에요. 한 번 설치하면 켤 때마다 알아서 새 버전을 받아요.

## 받기

- 윈도우 PC: [MiniBuddiesSetup.exe](https://github.com/sansan123123cc/MiniBuddies/releases/download/setup/MiniBuddiesSetup.exe) → 받아서 실행
- 안드로이드: [MiniBuddies.apk](https://github.com/sansan123123cc/MiniBuddies/releases/download/android/MiniBuddies.apk) → 받아서 설치 (출처를 알 수 없는 앱 설치 허용 필요)

윈도우에서 'PC 보호' 창이 뜨면 '추가 정보' → '실행'을 누르면 돼요.
